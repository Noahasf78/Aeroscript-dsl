# AeroScript

AeroScript is a domain-specific language for describing autonomous drone behavior. The project is implemented in Java and uses ANTLR4 to define and process the language grammar.

## Project Structure

- `src/` contains the Java implementation, grammar, and tests.
- `gradle/` and the Gradle wrapper provide the project build tooling.
- `docs/` contains the assignment reports.

## Build

Use the Gradle wrapper from the project root:

```bash
./gradlew build
```

On Windows, run:

```bat
gradlew.bat build
```
